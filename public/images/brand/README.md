# Where to save the logo

Put her logo files in **this folder** (`public/images/brand/`), then set
`brandLogo` in [`content/brand.ts`](../../../content/brand.ts). Nothing else
needs editing: the header, the mobile menu and the footer all read from that
one place.

Until you set it, those places show her name in the display face, which is a
perfectly respectable wordmark in the meantime.

---

## 1. The logo shown on the page

Save as one of these, in this folder:

```
public/images/brand/logo.svg        <- best
public/images/brand/logo.png        <- fine, transparent background
```

Then in `content/brand.ts` replace `export const brandLogo = null` with:

```ts
export const brandLogo: BrandLogo | null = {
  src: '/images/brand/logo.svg',
  width: 512,        // the file's real pixel size
  height: 128,
  displayHeight: 30, // how tall it appears in the header
};
```

The path starts at `/images/...`, **not** `/public/images/...` — that is how
files in `public/` are addressed.

### The dark-theme problem, and how to avoid it

The site has a light theme and a dark one. A logo in one fixed colour will be
invisible against one of them, so pick one of these:

**Best.** Supply an **SVG whose shapes use `currentColor`** instead of a fixed
colour. It then takes the site's text colour automatically and is correct in
both themes. Set `src` only. If a designer made the SVG, ask them for a
"currentColor" or "monochrome, inherits colour" version.

**Otherwise.** Supply two files and set both:

```ts
export const brandLogo: BrandLogo | null = {
  src: '/images/brand/logo-dark.svg',   // dark logo, for the light theme
  srcDark: '/images/brand/logo-light.svg', // light logo, for the dark theme
  width: 512,
  height: 128,
  displayHeight: 30,
};
```

The header swaps them when the visitor flips the theme.

### File requirements

- **SVG** is ideal: sharp at any size, tiny file.
- **PNG** must have a **transparent background** and be at least **3x** its
  display height (so 120px tall or more).
- **Never JPG.** JPG cannot store transparency, so the logo will sit in a
  visible white box.
- If the logo already contains her name, leave `showNameBeside` unset. If it is
  just a mark or monogram, set `showNameBeside: true` so her name appears next
  to it.

## 2. The browser tab icon (favicon)

This one does **not** go in this folder. Next.js picks it up from the `app/`
folder by filename:

```
app/icon.svg          (or icon.png, at least 512x512)
app/apple-icon.png    (180x180, for iPhone/iPad home screens)
```

Save the files there with exactly those names and they are wired up
automatically — no code change at all.

**There is currently a `app/favicon.ico` left over from the project template,
so the tab still shows a generic icon.** Delete it once you add `app/icon.svg`
or `app/icon.png`, otherwise the old one keeps winning.

A favicon is displayed at about 16-32 pixels. A full wordmark turns to mush at
that size — use a monogram, a single letter, or the mark without the name.

---

## 3. The social sharing card

The image shown when the site is shared on Facebook, WhatsApp, LinkedIn or
Instagram is generated by
[`app/[locale]/opengraph-image.tsx`](../../../app/%5Blocale%5D/opengraph-image.tsx).
It is currently typographic (her name set in the display face on the ivory
ground). Once the logo exists it can be placed on that card too. Ask and it
takes a few minutes.

## Summary

| What | Where to save it | Then what |
| --- | --- | --- |
| Page logo | `public/images/brand/logo.svg` | Set `brandLogo` in `content/brand.ts` |
| Dark-theme logo (only if the logo is a fixed colour) | `public/images/brand/logo-light.svg` | Set `srcDark` too |
| Browser tab icon | `app/icon.svg` | Delete `app/favicon.ico` |
| iPhone home screen icon | `app/apple-icon.png` (180x180) | Nothing |
| Social card | generated in code | Ask, once the logo exists |
